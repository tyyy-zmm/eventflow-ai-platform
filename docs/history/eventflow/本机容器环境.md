# 本机容器环境

仅本机开发实验，Compose项目名eventflow-local，与旧点评隔离。模型默认disabled，无真实模型费用。

| 服务 | 本机端口 | 持久数据 |
| --- | --- | --- |
| MySQL 8.4 | 127.0.0.1:13306 | mysql-data，eventflow及专用eventflow_it |
| Redis 7.4 | 127.0.0.1:16379 | redis-data，AOF开启，128MB/noeviction |
| Kafka 3.9.1 KRaft单节点 | 127.0.0.1:19092 | kafka-data，消息保留24小时及每分区256MB上限 |

所有暴露端口仅loopback。Kafka本地明文不用于生产；MySQL/Redis用随机密码。容器内存上限合计约3.25GB，另有Docker虚拟机和应用开销；日志每容器最多3个10MB文件。Kafka保留不是全局硬磁盘上限，不要随意大量创建topic/分区。

```bash
node scripts/init-local-env.mjs
bash scripts/local.sh up
bash scripts/local.sh status
bash scripts/local.sh start
```

init脚本生成600权限且被gitignore的.env，已存在不覆盖，不打印秘密。仅运行可信的本地.env，local.sh会source它。Compose自动读取.env，但Spring不会，必须通过local.sh启动或自行export。

```bash
bash scripts/local.sh integration
bash scripts/local.sh stop
```

integration会写专用eventflow_it表/测试topic，不自动清库；Redis与开发模式共享该独立项目的实例，禁止同时做缓存性能对照。stop保留数据。不要使用down -v，删除volume会丢失全部实验数据。密码初始化只对空MySQL卷生效，修改.env不会自动改变已有数据库密码。

应用运行时，在另一个终端执行bash scripts/local.sh smoke可验证登录、权限、健康及守恒，不打印密码/token，并撤销测试会话。本次已通过79项普通测试及2项真实中间件IT，见[安装验证报告](../experiments/local-environment-2026-09-18/README.md)。这不代表完整故障/性能实验完成。

本机Java17/Maven已保存于~/Library/Application Support/EventFlow/tools，local.sh自动选用，避免修改系统Java。其他电脑无此目录时使用PATH中的Java17/Maven。bash scripts/local.sh test可执行普通测试。首次启动账户local_user/local_admin的密码保存在.env，不在文档明文输出。应用仅监听127.0.0.1:8091；启动应用会持续运行，可用Ctrl+C退出。进一步测试边界见迁移与验证.md。

镜像使用官方维护的固定版本系列，具体digest以实际拉取后docker image inspect为准。本地单节点不证明高可用或生产容灾。

后续实验入口：bash scripts/local.sh experiments运行真正双进程及三处硬退出窗口，详见[双进程与故障实验](双进程与故障实验.md)。只适用于专用测试库，结束停止自建应用进程而不停止三个中间件。
