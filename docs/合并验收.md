## 复现

先 `bash run.sh init`、`bash run.sh up`。没有其他进程使用验收环境时执行 `bash run.sh verify`，完成后再启动浏览器验收服务，不能同时跑。

```bash
# 终端 1：完整后端验收结束后再启动
PLANNING_MODE=stub bash backend/scripts/verification.sh start --server.port=18096 --upgrade.demo-data=true
# 终端 2
API_TARGET=http://127.0.0.1:18096 DEV_PORT=4178 npm --prefix frontend run dev
# 终端 3；需要可用的 Playwright 及 Chrome
cd frontend
LIFE_URL=http://127.0.0.1:4178 LIFE_BROWSER_CHANNEL=chrome npm run test:e2e
```

可设置 PLAYWRIGHT_MODULE 为本机安装的 Playwright 模块路径。脚本不会自动安装浏览器。双实例短时缓存检查入口为 `bash backend/scripts/verification.sh multilevel-benchmark --smoke`；完整长稳、停机与容量实验已迁移脚本，但没有在本次合并中重新执行。

历史缓存 2.20 倍、40 请求/秒持续 15 分钟等指标保留其原版本归属。此次短时检查和功能回归不构成合并版的正式性能结论。
